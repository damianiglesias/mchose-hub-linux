AmnesiaOS

Operating system

A minimal Linux built from scratch that boots entirely into RAM. Shut it down and nothing remains on disk.

  • Boots entirely into RAM as an initramfs: nothing persists on disk after shutdown.
  • Built from scratch following Linux From Scratch, on Linux kernel 6.16.1 with a BusyBox userland.
  • DHCP networking with udhcpc.
  • Spanish keyboard layout support through loadkeys.
  • A quiet, silenced boot sequence.
  • Distributed as an ISO in the GitHub releases.
  • Linux From Scratch
  • Kernel 6.16.1
  • initramfs
  • BusyBox
