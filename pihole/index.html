Pi-hole & Unbound deploy

Automation

One script sets up a private, recursive DNS server on Ubuntu Server, with a static IP and hardening included.

  • Sets up Pi-hole with Unbound as a private, recursive DNS resolver.
  • Configures a static IP on the server.
  • Applies security hardening as part of the same run.
  • Automation with Bash and Ansible, with Docker in the toolbox.
  • Documentation of each component in the docs.
